Читанка

Завантажте книжку англійською. Під час читання торкніться слова, і побачите переклад. Працює без інтернету.

Переклад речень без інтернету Один раз завантажте перекладач (близько 30 МБ, краще через Wi-Fi). Словник для окремих слів уже вбудований.
Переклад через Claude

Claude перекладає слово саме в цьому реченні й пояснює ідіоми. Потрібен ключ Claude API (platform.claude.com) та інтернет. Ключ зберігається лише на цьому телефоні. Без ключа працюють словник і перекладач телефона.

Формати: EPUB, FB2, TXT
