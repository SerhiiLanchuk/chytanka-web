# Читанка — веб-версія для iPhone

Читалка англійських книжок з перекладом слів українською. Відкрийте сайт у Safari → «Поділитися» → «На початковий екран». Після першого відкриття працює без інтернету.

Ця папка збирається автоматично з основного проєкту командою `node scripts/build-pwa.mjs ../chytanka-web`. Не редагуйте файли тут вручну.
